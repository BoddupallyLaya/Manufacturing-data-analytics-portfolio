
# Manufacturing KPI Dashboard

## Project Overview

An industrial manufacturing analytics project
designed to monitor production performance,
quality metrics and operational efficiency.

## Objectives

- Analyse production output.
- Monitor product defects.
- Track machine downtime.
- Measure production efficiency.
- Identify quality improvement opportunities.

## Technologies

- Microsoft Power BI
- Excel
- Power Query
- DAX

## Key Metrics

- Total Production
- Defect Rate
- Machine Downtime
- Production Efficiency
- Overall Equipment Effectiveness (OEE)
